# How to automate with Claude

1. Read `AGENT_INDEX.md` in this folder first (about 2.4k tokens). Start at DECIDE to pick a route; each line points to a section like [§3].
2. Open `DIRECTORY.md` at that section only when you need the full explanation, code samples or sources.
3. Flags and product names change fast. Before relying on a CLI flag or price, check the doc linked in that section.
4. Blender-specific setup lives in the sister skill `blender-claude-mcp`.

Update this skill: `git -C ~/.claude/skills/claude-automation-patterns pull`
